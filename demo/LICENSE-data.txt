Este pacote de dados é disponibilizado sob a Open Database License (ODbL) v1.0:
https://opendatacommons.org/licenses/odbl/1-0/

O recorte original do OpenStreetMap está em itapipoca-roads.osm.json.gz.
O arquivo city.json é uma transformação dessa malha para o canvas do laboratório.
Restaurantes, pedidos, entregadores, turnos, trânsito, preparo e decisões são
sintéticos; nenhum deles representa uma operação comercial.

O manifesto contém configuração, origem e hashes dos arquivos. Os dados do
mapa estão disponíveis em JSON legível por máquina na demonstração pública.
O código do projeto continua sob a licença MIT do arquivo LICENSE na raiz.
