# Fontes da apresentação

Arquivos WOFF2 latinos servidos com o próprio site. Incluem os caracteres usados em português. As duas famílias usam a SIL Open Font License 1.1; as licenças originais acompanham os arquivos.

- Barlow Condensed, peso 600: [arquivo de origem no Google Fonts](https://fonts.gstatic.com/s/barlowcondensed/v13/HTxwL3I-JCGChYJ8VI-L6OO_au7B4873z3bWuYMBYro.woff2), [licença original](https://github.com/google/fonts/blob/main/ofl/barlowcondensed/OFL.txt).
- IBM Plex Sans, variável nos pesos 400 a 600: [arquivo de origem no Google Fonts](https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYbSB4Zh.woff2), [licença original](https://github.com/google/fonts/blob/main/ofl/ibmplexsans/OFL.txt).

Foram obtidos sem alteração dos binários. A hospedagem local e o preload evitam depender de conexões adicionais para a tipografia principal.
